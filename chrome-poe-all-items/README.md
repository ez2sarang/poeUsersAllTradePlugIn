# PoE 거래소 모든아이템

카카오 PoE 1 거래소의 아이템 결과에서 **귓속말** 오른쪽에 **모든아이템** 버튼을 추가합니다. 즉시 구매 매물에는 **은신처로 이동** 오른쪽에 표시되며, 오프라인 매물에서도 버튼을 쓸 수 있습니다. 버튼은 현재 리그와 판매자의 `계정명#숫자`로 공식 거래소의 전체 매물 목록을 새 탭에 엽니다.

## Chrome에 설치

1. Chrome 주소창에 `chrome://extensions`를 입력합니다.
2. **개발자 모드**를 켜고 **압축해제된 확장 프로그램을 로드합니다**를 선택합니다.
3. `manifest.json`이 있는 `chrome-poe-all-items` 폴더를 선택하고, 열린 거래소 탭을 새로고침합니다.

Brave에서는 `brave://extensions/`에서 같은 순서로 설치할 수 있습니다. [이미지 포함 설치 안내](https://github.com/ez2sarang/poeUsersAllTradePlugIn#설치-방법)
